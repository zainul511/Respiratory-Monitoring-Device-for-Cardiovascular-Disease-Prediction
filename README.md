# Respiratory-Monitoring-Device-for-Cardiovascular-Disease-Prediction
Wearable respiratory monitor using ESP32 &amp; 3x MPU6050s. Extracts high-fidelity breathing patterns via Incremental PCA &amp; DMP signal fusion. Includes ESP-IDF firmware (Dual I2C), Python dashboard (PyQt5), and 3D mechanical files for real-time cardiovascular analysis.
